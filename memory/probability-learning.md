## Day 1 学习记录 (2025-04-04)

### 核心概念

#### 1. 随机试验 (Random Experiment)
满足三个特征的试验：
- 可在相同条件下重复进行
- 所有可能结果事先已知
- 具体结果无法准确预知

**例子**：抛硬币、掷骰子、从用户池随机抽取一个用户

#### 2. 样本空间 (Sample Space)
所有可能结果的集合，记为 Ω 或 S

| 试验 | 样本空间 |
|------|----------|
| 抛一枚硬币 | {正面, 反面} 或 {H, T} |
| 掷一颗骰子 | {1, 2, 3, 4, 5, 6} |
| 抛两次硬币 | {HH, HT, TH, TT} |
| 连续射击直到命中 | {w₁, w₂, w₃, ...} (无限样本空间) |

#### 3. 随机事件 (Random Event)
样本空间的子集，用大写字母表示

**事件分类**：
- **基本事件**：单个样本点组成（如骰子掷出"3"）
- **复合事件**：多个基本事件的组合（如"掷出偶数" = {2, 4, 6}）
- **必然事件**：整个样本空间 Ω，一定会发生
- **不可能事件**：空集 ∅，一定不发生

#### 4. 事件的关系

**包含关系**：A ⊂ B，A 发生则 B 一定发生
**互斥关系**：A ∩ B = ∅，A 和 B 不能同时发生

### 直观例子

> **亚马逊运营场景**：假设你从最近 100 个订单中随机抽取 1 个订单检查
> - 样本空间：100个订单的编号集合
> - 事件 A = "抽到退货订单"
> - 事件 B = "抽到五星好评订单"
> - A 和 B 是互斥事件（一个订单不可能同时是退货又是五星好评）

### 今日公式
$$P(A) = \frac{\text{事件A包含的样本点数}}{\text{样本空间的总样本点数}}$$
