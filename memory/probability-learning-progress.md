## 第1天学习记录（2026-04-09）

### 核心概念：什么是概率？

**概率的定义**：概率是描述某个事件发生可能性的数值，取值范围在0到1之间。
- 0 = 不可能事件
- 1 = 必然事件
- 0.5 = 事件发生与不发生的可能性相等

**基本术语**：
1. **试验（Trial）**：产生明确结果的一次行动（如掷骰子、抛硬币）
2. **样本空间（Sample Space）**：所有可能结果的集合
   - 掷硬币：{正面, 反面}
   - 掷骰子：{1, 2, 3, 4, 5, 6}
3. **事件（Event）**：样本空间的子集，即我们关心的结果

### 概率的基本性质

1. **非负性**：P(A) ≥ 0，任何事件的概率都不小于0
2. **规范性**：P(Ω) = 1，样本空间的概率为1
3. **可加性**：互斥事件的概率可以相加
   - 掷骰子得到1或2的概率：P(1) + P(2) = 1/6 + 1/6 = 1/3

### 例子理解

**例子1：公平硬币**
- 样本空间 = {正面, 反面}
- P(正面) = 0.5，P(反面) = 0.5

**例子2：掷骰子**
- 样本空间 = {1, 2, 3, 4, 5, 6}
- P(任意一个数字) = 1/6 ≈ 0.167
- P(偶数) = P(2) + P(4) + P(6) = 3/6 = 0.5

**例子3：抽扑克牌**
- 样本空间 = 52张牌
- P(抽到A) = 4/52 = 1/13 ≈ 0.077
- P(抽到红桃) = 13/52 = 1/4 = 0.25

### 今日要点总结
- 概率是0到1之间的数值，表示事件发生的可能性
- 样本空间包含所有可能结果
- 事件的概率 = 事件包含的结果数 ÷ 样本空间总结果数（等可能情况下）

## 第2天学习记录（2026-04-11）

### 核心概念：条件概率与独立性

**条件概率的定义**：在已知事件B发生的条件下，事件A发生的概率，记为 P(A|B)。

**公式**：
$$P(A|B) = \\frac{P(A \\cap B)}{P(B)}, \\quad P(B) > 0$$

**直观理解**：知道B发生后，样本空间被"缩小"到B的范围内，重新计算A发生的比例。

### 乘法公式

由条件概率定义可直接推出：
$$P(A \\cap B) = P(A|B) \\times P(B) = P(B|A) \\times P(A)$$

### 事件的独立性

如果事件A和B **独立**，则一个事件的发生不影响另一个事件：
$$P(A|B) = P(A)$$

等价地：
$$P(A \\cap B) = P(A) \\times P(B)$$

### 全概率公式

若 $B_1, B_2, ..., B_n$ 构成样本空间的一个划分（互斥且穷尽），则：
$$P(A) = \\sum_{i=1}^{n} P(A|B_i) \\times P(B_i)$$

### 例子理解

**例子1：亚马逊运营场景（条件概率）**
> 假设你销售一款台灯，数据显示：
> - 总退货率 P(退货) = 5%
> - 包装破损的订单中，退货率 P(退货|包装破损) = 35%
> - 包装完好的订单中，退货率 P(退货|包装完好) = 2%
>
> 这说明"包装是否破损"极大地影响退货概率。如果你改善包装，预期退货率会从5%显著下降。

**例子2：抽牌（条件概率）**
- 从一副扑克中抽一张牌，P(抽到K) = 4/52 = 1/13
- 已知抽到的牌是黑色，P(抽到K|黑色) = 2/26 = 1/13
- 这里 P(抽到K|黑色) = P(抽到K)，说明"花色是黑色"与"是K"这两个事件**独立**

**例子3：独立性的常见误区**
- 连续抛硬币：第5次抛到正面的概率，不受前4次结果影响。每次 P(正面) = 0.5，这是独立事件。
- 很多人误以为"前面4次都是正面，第5次更可能是反面"——这叫赌徒谬误，是错误的。

**例子4：全概率公式应用**
> 你的广告来源有两类客户：
> - 自然流量客户（占70%），转化率 P(购买|自然) = 2%
> - 付费流量客户（占30%），转化率 P(购买|付费) = 5%
>
> 整体转化率 = 0.70 × 0.02 + 0.30 × 0.05 = 0.014 + 0.015 = 0.029 = **2.9%**

### 今日要点总结
- 条件概率是"在已知某事发生的前提下"重新计算的概率
- 独立事件：一个发生不影响另一个，满足 P(A∩B) = P(A)×P(B)
- 全概率公式：把复杂事件按不同情况拆分，加权求和得到总概率
- 亚马逊运营启示：识别影响转化率/退货率的关键条件变量，才能精准优化
