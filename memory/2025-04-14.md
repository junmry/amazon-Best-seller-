## 📚 概率论学习 - Day 1: 基础概念

### 今日学习要点

**1. 概率的定义**
概率是衡量某个事件发生可能性的数值，取值范围在 0 到 1 之间：
- P(A) = 0：事件不可能发生
- P(A) = 1：事件必然发生
- 0 < P(A) < 1：事件有一定可能性发生

**2. 样本空间 (Sample Space)**
样本空间 S 是一个随机试验所有可能结果的集合。

*例子*：掷一个六面骰子，样本空间 S = {1, 2, 3, 4, 5, 6}

**3. 事件 (Event)**
事件是样本空间的子集，代表我们感兴趣的某些结果。

*例子*："掷出偶数" 是一个事件，E = {2, 4, 6}

**4. 概率的基本性质**
- 非负性：P(A) ≥ 0
- 规范性：P(S) = 1
- 可加性：互斥事件的并集概率等于各事件概率之和
  - 若 A ∩ B = ∅，则 P(A ∪ B) = P(A) + P(B)

**5. 古典概型**
当所有基本结果等可能时：
P(A) = 事件A包含的基本结果数 / 样本空间的基本结果总数

*例子*：掷骰子得到偶数的概率 = 3/6 = 1/2

## 🇺🇸 社媒家具趋势洞察

### 1. 颜色趋势：从冷灰转向暖调
- **Mocha Mousse** (摩卡慕斯棕) 成为2025年度代表色
- 大地色系、陶土色、赭石色取代冷灰色
- 宝石色调（祖母绿、宝石蓝、酒红）作为点缀

### 2. 风格趋势：两大主流风格
- **"THE NEW RAW"**：原始自然材料，未处理木材、裸露混凝土
- **"RETRO REVERY"**：70年代怀旧风，天鹅绒表面、有机曲线

### 3. 材质趋势
- 深色木材（胡桃木、桃花心木）强势回归
- 天鹅绒、皮革、亚麻等高端面料
- 可持续材料关注度上升

### 4. 设计趋势
- **有机曲线**：圆角、流线型取代锐利直角
- **Color Drenching**：单一颜色覆盖墙面、家具、装饰
- **功能与美观并重**：尤其关注小空间储物方案

### 5. 消费者痛点（来自Reddit观察）
- 小空间储物需求旺盛
- 对耐用性要求提高（Buy It For Life 理念）
- 预算与品质的平衡
