## 📚 今日学习：概率论基础

### 1. 概率的基本概念

**样本空间 (Sample Space)**
- 定义：随机试验所有可能结果的集合，记为 Ω
- 例子：掷骰子的样本空间 Ω = {1, 2, 3, 4, 5, 6}

**事件 (Event)**
- 定义：样本空间的子集
- 例子："掷出偶数" 的事件 A = {2, 4, 6}

**概率 (Probability)**
- 定义：事件发生的可能性大小的度量，记为 P(A)
- 取值范围：0 ≤ P(A) ≤ 1

### 2. 概率公理（Kolmogorov公理）

1. **非负性**：对任意事件 A，P(A) ≥ 0
2. **规范性**：P(Ω) = 1（必然事件概率为1）
3. **可列可加性**：若 A₁, A₂, ... 互不相容，则 P(A₁∪A₂∪...) = P(A₁) + P(A₂) + ...

### 3. 基本公式

**加法公式**：P(A∪B) = P(A) + P(B) - P(A∩B)

**补事件概率**：P(A') = 1 - P(A)

### 4. 今日案例

🎲 **掷骰子问题**：
- 问：掷一次骰子，得到偶数或大于4的数的概率？
- A = {2, 4, 6}（偶数），B = {5, 6}（大于4）
- P(A) = 3/6 = 0.5
- P(B) = 2/6 ≈ 0.333
- P(A∩B) = 1/6（只有6）
- P(A∪B) = 0.5 + 0.333 - 0.167 = 0.667

### 📌 详细趋势分析

**1. 色彩趋势：告别冷灰，拥抱温暖**
- **OUT**：冷灰色、 stark white、高对比黑白
- **IN**：
  - 暖中性：驼色(camel)、沙色(sand)、米白(warm ivory)
  - 大地色：陶土色(terracotta)、赭石(ochre)、焦糖(caramel)
  - 柔和绿：橄榄绿(olive)、苔藓绿(mossy green)
- 驱动因素：人们对"疗愈感"和"自然连接"的需求

**2. 模块化沙发 = 2026客厅之王**
- r/malelivingspace 和 r/InteriorDesign 上讨论度极高
- Cloud Couch 热度不减，因其模块化DNA
- 消费者痛点：空间多变（办公室→影院→社交空间）
- 需求关键词：endless layouts、small-space friendly

**3. 曲线家具：柔软即奢华**
- "Sharp edges are out — rounded, enveloping silhouettes are in"
- 弧形沙发、圆形咖啡桌、圆角椅子
- 心理学解释：圆润设计创造安全感和放松感
- 面料：天鹅绒、圈圈呢(bouclé)、刷毛亚麻

**4. 小空间解决方案爆发**
- 城市公寓面积10年减少10-15%
- 远程办公需求增长35%
- 热门单品：
  - 升降茶几(lift-top coffee table) → 工作桌
  - 折叠沙发床
  - 墨菲床(Murphy bed) + 书桌整合
  - 隐藏储物长凳

**5. Japandi持续统治**
- 日式的wabi-sabi + 北欧的hygge
- 低重心家具、浅色木材（白橡木、梣木）
- 少即是多，质量优于炫耀

**6. Quiet Luxury（静奢风）**
- 干净线条+优质材料+精致细节
- 不再追求炫耀性消费，而是" effortless, elevated, timeless"
