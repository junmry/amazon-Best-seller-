## 使用方法

### 一键运行完整工作流

```bash
cd ~/.openclaw/workspace
./scripts/run_workflow.sh "游戏椅关键词.xlsx" "BSR_Gaming_Chair.xlsx"
```

### 单独运行关键词拆词

```bash
python3 scripts/keyword_pipeline.py "关键词文件.xlsx" "输出目录/"
```

### 单独运行BSR分析

```bash
python3 scripts/bsr_analyzer.py "BSR文件.xlsx" "输出目录/"
```

## 核心功能

### 1. 智能列识别
自动识别中英文列名，无需手动调整格式。

### 2. 多维度拆词
9大维度自动分类：颜色、尺码、人群、款式、材质、场景、功能、价格、品牌。

### 3. 高价值词筛选
自动识别1000-50000搜索量的高价值长尾词，标注埋词位置建议。

### 4. 数据洞察
- 搜索量集中度分析
- 各维度TOP词统计
- 平均搜索量/中位数
- 埋词优先级建议

### 5. BSR竞品对标
- 标题词频分析
- 五点主题提取
- 价格区间分布
- 品牌竞争格局

## 埋词SOP

### 标题埋词
1. 选择搜索量最高的核心词（gaming chair, computer chair）
2. 加入高占比功能词（footrest, lumbar support, ergonomic）
3. 根据产品特点选择1-2个维度词（颜色/尺寸/场景）
4. 控制长度在150-200字符

### 五点埋词
1. 第1点：舒适度相关（ergonomic, support, comfortable）
2. 第2点：材质工艺（leather, fabric, foam, quality）
3. 第3点：功能特性（adjustable, footrest, massage）
4. 第4点：耐用性（durable, heavy duty, stable）
5. 第5点：售后安装（easy assembly, warranty, service）

### 后台Search Terms
1. 收集所有维度词
2. 加入长尾组合词
3. 加入竞品品牌词（可选）
4. 控制在249字节以内

## 常见问题

### Q: 列名识别失败怎么办？
A: 确保文件第一行是列名，包含"关键词"或"keyword"字样。

### Q: 搜索量为0的数据如何处理？
A: 程序会自动过滤搜索量为0的数据。

### Q: 支持哪些文件格式？
A: 目前支持 .xlsx 格式，.csv 可先用 Excel 另存为 xlsx。

### Q: 输出目录可以自定义吗？
A: 可以，运行脚本时传入第二个参数作为输出目录。
