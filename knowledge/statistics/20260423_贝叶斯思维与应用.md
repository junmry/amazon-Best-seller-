# 贝叶斯思维与应用\n\n
## 贝叶斯思维

### 核心公式
```
P(H|D) = P(D|H) * P(H) / P(D)

后验概率 = 似然 * 先验 / 证据
```

### 与频率派区别
- **频率派**: 参数是固定的,数据是随机的
- **贝叶斯**: 参数是随机的,用概率表示不确定性

### 亚马逊应用: 转化率预测
新广告跑了100点击,5转化(转化率5%):
- **频率派**: 转化率就是5%
- **贝叶斯**: 先验认为转化率~Beta(1,1)
- **后验**: 转化率~Beta(6,96),均值5.8%,有不确定性区间

### 优势
- 自然处理小样本(用先验补充信息)
- 输出概率分布而非点估计
- 可逐步更新信念
