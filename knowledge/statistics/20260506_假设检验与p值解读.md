# 假设检验与p值解读\n\n
## 假设检验核心概念

### 基本流程
1. **建立假设** - H0(原假设) vs H1(备择假设)
2. **选择检验方法** - t检验/卡方检验/方差分析等
3. **确定显著性水平** - 通常alpha=0.05
4. **计算p值** - 观测到当前或更极端结果的概率
5. **做出决策** - p < alpha拒绝H0

### p值的正确理解
- 正确: p=0.03表示:若H0为真,只有3%概率看到如此极端的数据
- 错误: 不是"H0为假的概率"
- 错误: 不是"结果重要的概率"

### 亚马逊应用示例
测试新主图是否提升点击率:
- H0: 新图点击率 <= 旧图
- H1: 新图点击率 > 旧图
- 收集数据 -> 计算p值 -> 若p<0.05则更换主图
