# 时间序列分析基础\n\n
## 时间序列分解

### 组成成分
```
Y(t) = Trend(t) + Seasonal(t) + Cyclical(t) + Error(t)

趋势(Trend): 长期方向
季节性(Seasonal): 固定周期波动
周期性(Cyclical): 非固定周期波动
随机(Random): 不可解释部分
```

### 分析方法
- **移动平均**: 平滑短期波动看趋势
- **同比/环比**: 消除季节性影响
- **STL分解**: 分离趋势/季节/残差

### 亚马逊应用
- 销量预测(考虑季节性)
- 异常检测(识别突发波动)
- 趋势判断(增长/下降/平稳)

### 注意事项
- 时间序列数据不自独立(今天销量和昨天相关)
- 不能用普通回归方法
- 需要专门的时间序列模型(ARIMA等)
