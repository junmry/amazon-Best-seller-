# 数据可视化原则\n\n
## 可视化最佳实践

### 选择图表类型
| 目的 | 推荐图表 |
|------|----------|
| 比较数值 | 柱状图/条形图 |
| 看趋势 | 折线图/面积图 |
| 看分布 | 直方图/箱线图 |
| 看占比 | 饼图(少用)/堆叠图 |
| 看关系 | 散点图/热力图 |

### 设计原则
1. **简化**: 去除无意义的装饰
2. **突出**: 用颜色强调关键信息
3. **标注**: 添加必要的说明文字
4. **一致**: 同组图表保持风格一致

### 亚马逊报告常用
- 销售趋势折线图
- 品类占比饼图
- 关键词表现条形图
- 时间序列热力图

### 工具推荐
- Python: matplotlib/seaborn/plotly
- Excel: 基础图表够用
- Tableau/Looker: 交互式仪表板
