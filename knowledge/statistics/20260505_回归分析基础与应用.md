# 回归分析基础与应用\n\n
## 线性回归入门

### 简单线性回归
```
y = beta0 + beta1*x + epsilon

y: 因变量(如销量)
x: 自变量(如广告花费)
beta0: 截距(x=0时的y值)
beta1: 斜率(x每增1,y变化多少)
epsilon: 误差项
```

### 关键指标
- **R²**: 模型解释了多少变异(0-1)
- **p值(系数)**: 该变量是否显著
- **残差**: 预测值与实际值差异

### 多元回归
```
sales = beta0 + beta1*ad_spend + beta2*price + beta3*reviews + epsilon
```

### 注意事项
- 检查残差正态性
- 多重共线性(自变量高度相关)
- 异常值影响
