# 样本量计算与统计功效\n\n
## 统计功效(Statistical Power)

### 定义
当H1为真时,正确拒绝H0的概率.
- 通常要求Power >= 0.8 (80%)

### 影响因素
1. **效应量** - 差异越大,越易检测
2. **样本量** - 样本越大,Power越高
3. **显著性水平** - alpha越大,Power越高
4. **方差** - 数据波动越小,Power越高

### 样本量公式
```
两组均值比较: n = 16*sigma²/delta²
两组比例比较: n = (Z(1-alpha/2) + Z(1-beta))² * 2p(1-p) / (p1-p2)²
```

### 实际应用
广告测试需要多少点击?
- 预期转化率提升: 10%->12%
- 所需样本: 每组约3000点击
- 若日点击量100,需跑30天
