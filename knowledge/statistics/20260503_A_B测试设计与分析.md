# A/B测试设计与分析\n\n
## A/B测试完整指南

### 设计原则
1. **随机分组** - 确保两组可比
2. **单一变量** - 一次只测一个改动
3. **足够样本** - 提前计算所需样本量
4. **运行时长** - 至少1-2个完整周期

### 样本量计算
```
n = 16 * sigma² / delta²

sigma: 指标标准差
delta: 期望检测的最小差异
```

### 分析步骤
1. 检查分组均衡性
2. 计算指标差异
3. 进行统计检验
4. 计算置信区间
5. 考虑实际显著性

### 亚马逊应用
- 主图A/B测试(Manage Your Experiments)
- 标题测试
- 价格测试
- 广告创意测试

### 常见错误
- 过早停止(p-hacking)
- 多重测试不校正
- 忽视segment差异
