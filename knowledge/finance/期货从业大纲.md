## 重点计算题型

### 套期保值盈亏计算
```
套期保值盈亏 = 现货市场盈亏 + 期货市场盈亏
           = (S_2 - S_1) + (F_1 - F_2)
           = 基差变动
```

### 基差计算
```
基差 = 现货价格 - 期货价格
基差走强：基差数值变大（正向市场变负向，或负向市场更负）
基差走弱：基差数值变小
```

### 保证金计算
```
初始保证金 = 合约价值 × 保证金比例
维持保证金 = 初始保证金 × 维持保证金比例
追加保证金 = 初始保证金 - 当前权益
```

### 跨期套利盈亏
```
牛市套利（买近卖远）：
盈亏 = (平仓时近月价差 - 开仓时近月价差) × 合约乘数

熊市套利（卖近买远）：
盈亏 = (开仓时近月价差 - 平仓时近月价差) × 合约乘数
```

### 期权盈亏平衡点
```
买入看涨期权：盈亏平衡点 = 执行价格 + 权利金
买入看跌期权：盈亏平衡点 = 执行价格 - 权利金
卖出看涨期权：盈亏平衡点 = 执行价格 + 权利金
卖出看跌期权：盈亏平衡点 = 执行价格 - 权利金
```
