## 重点公式

### 科目二常用公式

**债券估值：**
```
债券价格 = Σ(利息/(1+r)^t) + 面值/(1+r)^n
```

**久期：**
```
麦考利久期 = Σ(t × PV(CF_t)) / 价格
修正久期 = 麦考利久期 / (1 + y)
```

**CAPM：**
```
E(R_i) = R_f + β_i × (E(R_m) - R_f)
```

**夏普比率：**
```
Sharpe Ratio = (R_p - R_f) / σ_p
```

** Jensen's Alpha：**
```
α = R_p - [R_f + β_p × (R_m - R_f)]
```
