# 亚马逊SEO最佳实践\n\n
## 亚马逊SEO完整指南

### 标题优化
```
公式: 品牌 + 核心关键词 + 尺寸/数量 + 关键特性 + 适用场景
示例: KEIKI 78" Sectional Sofa, L-Shaped Couch with Chaise, 
      Modern Velvet Upholstered for Living Room, Beige
限制: 200字符内,前80字符最重要
```

### 五点描述优化
- 每点控制在200字符内
- 首字母大写,其余小写(更友好)
- 包含1-2个关键词
- 聚焦痛点和解决方案

### 后台搜索词
- 250字节限制(约50个词)
- 小写,无标点,空格分隔
- 不重复标题已用词
- 包含同义词/缩写/常见拼写错误

### A+内容SEO
- 图片Alt Text填写关键词
- 图文结合提升停留时间
- 品牌故事建立信任
- 对比图突出差异化

### 排名提升 checklist
- [ ] 关键词在标题/五点/搜索词全覆盖
- [ ] 主图点击率 > 0.3%
- [ ] 转化率 > 10%
- [ ] 评论4.3星以上
- [ ] 库存充足不断货
