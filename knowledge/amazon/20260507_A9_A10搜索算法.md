# A9/A10搜索算法原理与排名因素\n\n
## A9/A10搜索算法核心

### 排名因素权重
1. **相关性 (40%)** - 标题/描述/后台关键词匹配度
2. **销量速度 (30%)** - 单位时间内订单量
3. **转化率 (20%)** - 点击率 + 购买转化
4. **客户满意度 (10%)** - 评论/退货率/响应速度

### A10 vs A9 变化
- A10更强调站外流量和品牌价值
- 外部引流权重提升
- 点击率和转化率权重增加

### 优化建议
- 确保关键词自然出现在标题前80字符
- 提升主图点击率(A/B测试)
- 控制退货率 < 5%
- 获取高质量评论(Vine计划)
