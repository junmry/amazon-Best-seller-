# FBA费用结构与利润计算\n\n
## FBA费用详解

### 费用构成
1. **配送费** - 按尺寸重量分级
2. **仓储费** - 按月体积计费(淡旺季不同)
3. **长期仓储费** - 库存超365天
4. **移除/弃置费** - 处理滞销库存
5. **退货处理费** - 部分类目收取

### 利润率计算
```
毛利润 = 售价 - 产品成本 - FBA费用 - 佣金(8-15%)
净利润 = 毛利润 - 广告费 - 其他运营费用
利润率 = 净利润 / 售价 * 100%
```

### 健康利润率
- **最低存活线**: 15%
- **健康水平**: 25-35%
- **优秀水平**: 35%+

### 成本优化
- 优化包装尺寸降低配送费
- 旺季前清库存避免长期仓储费
- 提高售价而非压缩成本(后者有限)
