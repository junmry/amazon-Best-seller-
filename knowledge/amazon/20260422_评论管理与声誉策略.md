# 评论管理与声誉策略\n\n
## 评论体系运营

### 评论权重因素
- **Vine评论** - 权重最高,带绿标
- **图片/视频评论** - 权重较高
- **长文字评论** - 优于短评
- **verified purchase** - 必须的

### 获取评论方法
1. **Vine计划** - 新品30件免费送测
2. **Request a Review** - 订单30天内按钮
3. **售后邮件** - 合规的客服跟进
4. **产品卡片** - 包装内放售后卡

### 差评处理
- 24小时内响应
- 专业礼貌,不辩解
- 尝试解决问题(退款/换货)
- 请求更新评论(不强制)

### 差评预警指标
- 退货率 > 5%
- 1-2星评论占比 > 10%
- 高频负面关键词出现
