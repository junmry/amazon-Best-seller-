# Listing转化率优化方法\n\n
## 转化率优化系统

### 影响因素
1. **主图质量** - 决定点击率
2. **价格竞争力** - Buy Box关键
3. **评论数量与星级** - 社会证明
4. **标题清晰度** - 5秒内理解产品
5. **五点卖点** - 解决痛点

### 优化检查清单
- [ ] 主图: 白底/占图85%/清晰无水印
- [ ] 辅图: 场景图/尺寸图/对比图/细节图
- [ ] 标题: 品牌+核心词+关键属性 < 200字符
- [ ] 价格: 竞品中位数±10%
- [ ] 评论: 4.3星以上,数量>50
- [ ] A+页面: 品牌故事+产品详情+使用场景

### 测试方法
- 用Manage Your Experiments做A/B测试
- 一次只改一个变量
- 至少跑2周收集数据
