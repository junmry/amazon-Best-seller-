# 价格弹性与动态定价\n\n
## 定价策略分析

### 价格弹性概念
```
弹性系数 = (销量变化%) / (价格变化%)
弹性 > 1: 弹性大,降价能提升总收入
弹性 < 1: 弹性小,提价能提升总收入
```

### 定价方法
1. **成本加成法** - 成本 * (1+目标利润率)
2. **竞品对标法** - 参考竞品定价±10%
3. **价值定价法** - 按客户感知价值定价
4. **动态定价** - 根据供需自动调价

### 动态定价工具
- **RepricerExpress**: 规则化调价
- **SellerSnap**: 基于博弈论算法
- **Feedvisor**: AI驱动定价

### 定价禁忌
- 频繁大幅调价(影响Buy Box)
- 价格歧视(不同买家不同价)
- 低于成本长期销售
