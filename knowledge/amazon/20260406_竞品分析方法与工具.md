# 竞品分析方法与工具\n\n
## 竞品分析框架

### 分析维度
1. **市场规模** - BSR反推月销量
2. **价格策略** - 历史价格走势(Keepa)
3. **评论分析** - 星级分布/高频词/痛点
4. **流量来源** - 自然vs广告占比估算
5. **Listing质量** - 图片/文案/A+评分

### 工具组合
- **Jungle Scout**: 销量估算/市场分析
- **Helium 10**: 关键词/竞品追踪
- **Keepa**: 价格历史/BSR趋势
- **SellerApp**: 广告分析/关键词
