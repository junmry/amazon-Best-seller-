# 库存管理与IPI优化\n\n
## 库存绩效指标(IPI)

### IPI计算因素
1. **冗余库存** - 超90天库存占比
2. **售出率** - 90天销量/平均库存
3. **无在售库存** - 可售但Listing关闭
4. **库存率** - 过去30天有货率

### IPI阈值
- **优秀**: 550+ (无限库容)
- **及格**: 450-550 (标准库容)
- **危险**: <450 (库容受限)

### 优化策略
- 滞销品及时降价/促销清货
- 热销品保持30-60天库存
- 避免断货(影响排名)
- 删除不可售库存

### 补货公式
```
补货量 = (日均销量 * 补货周期) + 安全库存 - 在途库存
安全库存 = 日均销量 * 7天
```
