# ACOS/TACOS优化策略\n\n
## 广告效率指标体系

### 核心公式
- **ACOS** = 广告花费 / 广告销售额
- **TACOS** = 广告花费 / 总销售额(含自然单)
- **ROAS** = 广告销售额 / 广告花费 = 1/ACOS

### 健康指标参考
| 指标 | 新品期 | 成长期 | 成熟期 |
|------|--------|--------|--------|
| ACOS | 50-80% | 30-50% | 15-30% |
| TACOS | 20-40% | 15-25% | 8-15% |

### 优化方法
1. **否定关键词** - 每周检查搜索词报告,否定无效词
2. **竞价调整** - ACOS高则降竞价,低则提竞价
3. **分时调价** - 高转化时段提价,低转化降价
4. **ASIN定位** - 定位互补品而非直接竞品
