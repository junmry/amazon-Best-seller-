# 求是系列方法论

求是系列源于毛泽东思想的核心方法论，为 AI Agent 提供系统化的战略思维与执行框架。

## 包含的 SKILL

| SKILL | 核心要义 |
|------|----------|
| qiushi-spark | 星火燎原——建立根据地，不做流寇 |
| qiushi-mass-line | 群众路线——从群众中来，到群众中去 |
| qiushi-arming-thought | 武装头脑——理论指导实践 |
| qiushi-concentrate-force | 集中优势力量——关键点突破 |
| qiushi-protracted-war | 持久战——分阶段推进 |
| qiushi-investigation | 调查研究——没有调查没有发言权 |
| qiushi-practice | 实践论——实践出真知 |
| qiushi-contradiction | 矛盾论——抓住主要矛盾 |
| qiushi-criticism | 批评与自我批评——持续改进 |

## 使用场景

- **项目启动**：用星火燎原确定核心切入点
- **问题分析**：用矛盾论抓住主要矛盾
- **方案制定**：用调查研究+实践论验证
- **资源分配**：用集中优势力量突破关键点
- **长期规划**：用持久战分阶段推进
