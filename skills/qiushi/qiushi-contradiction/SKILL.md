# 矛盾分析法

## 核心要义

任何复杂问题中都存在多重矛盾，但**主要矛盾**决定事物的发展方向。解决了主要矛盾，其他矛盾往往迎刃而解。

## 操作步骤

1. **列出所有矛盾**：把问题中所有冲突、张力、两难全部列出来，不遗漏
2. **识别主要矛盾**：哪一个矛盾是核心？解决它，其他问题会跟着松动？
3. **分析矛盾的主次方面**：在主要矛盾中，哪一方是主导方面？
4. **制定针对性策略**：集中资源打主要矛盾，其他矛盾暂时搁置或次要处理
5. **注意矛盾转化**：随着情况变化，主要矛盾可能转移，及时重新识别

## 典型应用

- 项目卡住了：找出是资源矛盾、需求矛盾还是人的矛盾
- 方案有多个问题：找出哪个问题不解决，其他问题解决了也没用
- 竞争分析：找出对手的核心优势（主要矛盾的主要方面）

## 输出格式

分析时明确标注：
- 主要矛盾：[一句话描述]
- 当前主要方面：[哪一侧占主导]
- 建议突破口：[针对主要矛盾的具体行动]
