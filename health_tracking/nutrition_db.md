## 本周推荐食谱库（不吃辣）

1. 燕麦牛奶 + 水煮蛋 + 苹果
2. 全麦面包 + 花生酱 + 牛奶

4. 玉米 + 水煮蛋 + 酸奶

### 午餐选项
1. 番茄炒蛋 + 米饭 + 清炒时蔬
2. 香煎鸡胸肉 + 杂粮饭 + 西兰花
3. 清蒸鱼 + 米饭 + 凉拌菠菜
4. 牛肉炒芹菜 + 米饭 + 番茄蛋汤

1. 豆腐汤 + 杂粮馒头 + 凉拌黄瓜
2. 三文鱼 + 蒸南瓜 + 清炒芥蓝
3. 鸡蛋蔬菜面 + 牛奶
4. 白灼虾 + 杂粮饭 + 清炒油麦菜
