# First $1K 每日任务清单

## 📋 双周循环体系说明

- **产出周（奇数周）**：内容创作为主，完成1篇主系列长文+5-8条微内容
- **体系周（偶数周）**：复盘优化为主，深度学习+数据分析+模板迭代

---

## 🕐 每日三大时段

### 1️⃣ 输入时段（30-45分钟）

**产出周任务**：
- [ ] 行业文章/热点扫描
- [ ] 素材收集（案例、数据、金句）
- [ ] 微内容灵感记录

**体系周任务**：
- [ ] 原著阅读（《One Thousand Ways》）
- [ ] 深度长文学习
- [ ] 投资哲学课程/播客

**最佳时间**：早晨 7:00-8:00 或 通勤时间

---

### 2️⃣ 创作/体系时段（45分钟）

**产出周 - 按日轮转**：
| 星期 | 核心任务 | 交付物 |
|------|----------|--------|
| 周一 | 大纲撰写 | 结构化大纲（钩子→原著→现代→WWBD→行动清单） |
| 周二 | 初稿前半（1000-1500字） | 完整初稿50% |
| 周三 | 初稿后半（1000-1500字） | 完整初稿 |
| 周四 | 编辑精修 | 定稿 |
| 周五 | 微内容拆解 | 5-8条微内容 |

**体系周任务**：
- [ ] 数据复盘（阅读/点赞/转发/评论分析）
- [ ] 选题库整理（ICE评分更新）
- [ ] 素材库归档
- [ ] 模板优化
- [ ] 下两周选题规划

**最佳时间**：晚上 20:00-21:00（深度工作时段）

**改良番茄法**：
- 关闭手机通知
- 开启飞行模式
- 45分钟专注单一任务
- 结束5分钟记录进度

---

### 3️⃣ 发布/互动时段（15分钟）

**产出周任务**：
- [ ] 平台发布（小红书/公众号/B站）
- [ ] 评论回复
- [ ] 数据快速浏览

**体系周任务**：
- [ ] 轻量互动
- [ ] 评论回复（强度减半）
- [ ] 社区维护

**最佳时间**：午休 12:30-12:45 或 晚间 21:00-21:15

---

## 🎯 每周深度工作块（周末）

### 产出周周末（周六/日）
- **深度块A（90分钟）**：主系列终稿完成
- **深度块B（90分钟）**：微内容精修 + 封面制作

### 体系周周末（周六/日）
- **复盘块A（90分钟）**：数据分析 + 质量评估 + 反馈汇总
- **复盘块B（90分钟）**：策略调整 + 详细计划

---

## ✅ 发布前7项必检清单

任何内容发布前必须打勾：

1. [ ] **标题**：含数字+对比元素+好奇心钩子
2. [ ] **开篇**：300字内锚定现代场景，让读者产生"这和我有关"的直觉
3. [ ] **数据**：每个关键数据点有来源标注
4. [ ] **对比**：古今对照到达机制层面而非表面相似
5. [ ] **框架**：至少应用1个巴菲特框架维度（护城河/安全边际/能力圈/复利）
6. [ ] **行动**：包含3个读者"今天就能做"的具体动作
7. [ ] **金句**：至少1句可截图传播的金句

## 🤖 AI辅助提示词（随时调用）

### 研究助手
```
你是资深商业史研究员。请搜索并整理关于[主题]的历史案例（≥3个，跨度≥50年）
和现代变体（≥2个，近5年内）。每个案例包含：时间、地点、核心人物、关键决策、
可量化结果。标注来源。
```

### 巴菲特式分析
```
你是巴菲特框架专家。请分析[案例]：
①护城河类型/宽度/可持续性
②决策者是否在能力圈内
③安全边际评估
④时间复利效应
⑤市场先生隐喻
```

### 微内容提取
```
你是内容编辑。请从以下长文中提取5条微内容：
框架提炼卡×2 + 术语解析卡×2 + 洞察摘录卡×1
每条含标题+正文（≤150字）+适合平台。
长文：[粘贴]
```

### 编辑润色
```
你是资深商业内容编辑。请润色以下文章，检查：
①结构清晰度
②案例是否有机制分析
③术语是否有大白话解释
④反常识浓度
⑤数据来源
保持原文框架。
```

## 💡 执行建议

1. **前8周是磨合期**：超时50%完全正常，关键是记录实际用时，在第3个Sprint前调整基准
2. **批量处理同类任务**：可减少30-40%的认知切换损耗
3. **SOP减少决策消耗**：80%的重复工作交给系统，20%留给真正决定差异化的判断
4. **AI使用三条铁律**：
   - AI辅助研究，人类做判断
   - AI生成初稿，人类注入洞察
   - AI优化表达，人类把关质量
