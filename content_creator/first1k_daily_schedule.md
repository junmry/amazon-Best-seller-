# First $1K 内容创业日程体系

> 基于双周循环工作法 | 产出周（创作）↔ 体系周（复盘）

---

## 🔄 核心逻辑：双周循环

```
Week 1（奇数周）→ 产出周：内容创作 → 完成1篇主系列长文 + 5-8条微内容
Week 2（偶数周）→ 体系周：复盘优化 → 深度学习 + 数据分析 + 模板迭代
```

**设计原理**：输入-输出交替节奏，防止创作者倦怠（研究显示41%创作者经历倦怠）

---

## 📅 每日日程结构（平日）

### ☀️ 时段一：输入时段（30-45分钟）

| 周类型 | 任务内容 | 具体动作 |
|--------|----------|----------|
| **产出周** | 浅层输入 | 行业文章扫描、热点追踪、素材收集、微内容灵感记录 |
| **体系周** | 深度输入 | 原著阅读（《One Thousand Ways》）、投资哲学学习、深度长文 |

**改良番茄法**：关闭通知 → 飞行模式 → 专注输入 → 5分钟记录要点

---

### 📝 时段二：创作/体系时段（45分钟）

#### 产出周 - 按日轮转制

| 星期 | 任务 | 交付物 | 时间基准 |
|------|------|--------|----------|
| **周一** | 大纲撰写 | 结构化大纲（钩子→原著→现代→WWBD→行动清单） | 30min |
| **周二** | 初稿前半 | 1000-1500字初稿 | 45min |
| **周三** | 初稿后半 | 完成完整初稿（2500-3500字） | 45min |
| **周四** | 编辑精修 | 定稿（7项必检清单验收） | 45min |
| **周五** | 微内容拆解 | 5-8条微内容（框架卡/术语卡/洞察卡） | 45min |

#### 体系周 - 基础设施周

| 任务类别 | 具体内容 |
|----------|----------|
| **数据复盘** | 阅读/点赞/转发/评论分析、ICE评分权重调整 |
| **素材库整理** | 案例素材卡归档、选题库更新（新增≥5个选题） |
| **模板优化** | 内容模板v迭代、SOP流程优化 |
| **选题规划** | 下两周选题排期、Sprint计划制定 |

---

### 📱 时段三：发布/互动时段（15分钟）

| 周类型 | 任务 |
|--------|------|
| **产出周** | 平台发布（小红书/公众号/B站）、评论回复、数据快速浏览 |
| **体系周** | 轻量互动、评论回复（强度减半）、社区维护 |

## 🎯 周末深度工作块

### 产出周周末（周六/日）

```
深度块A（90分钟）→ 主系列长文终稿完成
↓ 休息15分钟
深度块B（90分钟）→ 微内容精修 + 封面制作（Canva模板）
```

**批量策略**：同类任务集中处理，效率提升30-40%

### 体系周周末（周六/日）

```
复盘块A（90分钟）→ 数据审计 + 时间效率审计 + 质量评估 + 反馈汇总
↓ 休息
复盘块B（90分钟）→ 策略调整 + 知识库更新 + 下两周详细计划
```

## ✅ 内容发布7项必检清单

发布前必须全部打勾：

1. [ ] **标题**：含数字+对比元素+好奇心钩子
2. [ ] **开篇**：300字内锚定现代场景，读者产生"这和我有关"直觉
3. [ ] **数据**：每个关键数据点有来源标注
4. [ ] **对比**：古今对照到达机制层面，非表面相似
5. [ ] **框架**：至少1个巴菲特框架维度（护城河/安全边际/能力圈/复利/市场先生）
6. [ ] **行动**：包含3个读者"今天就能做"的具体动作
7. [ ] **金句**：至少1句可截图传播的金句

```

```

```
②决策者是否在能力圈内
③安全边际评估

```

```
每条含标题+正文（≤150字）+适合平台。

```


## 📊 ICE选题评分模型

| 维度 | 含义 | 评分（1-5）|
|------|------|-----------|
| **I - Impact** | 对读者的价值 | 5分=改变核心认知 |
| **C - Confidence** | 对内容的把握 | 5分=有充分案例支撑 |
| **E - Ease** | 生产难度 | 5分=素材齐全可快速成文 |

**总分计算**：I × C × E（三项相乘）

| 分数区间 | 优先级 | 动作 |
|----------|--------|------|
| 100-125分 | P0 | 立即排期 |
| 60-99分 | P1 | 近期Sprint |
| 30-59分 | P2 | 储备 |
| <30分 | - | 归档 |

## ⚠️ AI使用三条铁律

1. **AI辅助研究，人类做判断** —— AI可能给出来源存疑的数据，每个数据点必须经人类验证
2. **AI生成初稿，人类注入洞察** —— AI写得出通顺段落，写不出"反常识发现"
3. **AI优化表达，人类把关质量** —— 发布前的7项必检清单永远由人类逐项确认

## 💡 关键执行原则

1. **前8周是磨合期**：超时50%完全正常，关键是记录实际用时
2. **批量处理同类任务**：减少认知切换损耗，效率提升30-40%
3. **SOP减少决策消耗**：把80%重复工作交给系统，20%留给差异化判断
4. **节奏比速度重要**：先确保能以这个节奏跑完12周，再考虑加速
5. **兼职创作者最大敌人**：不是时间不够，而是节奏不可持续
