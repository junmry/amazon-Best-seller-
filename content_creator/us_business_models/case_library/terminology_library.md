## 第一部分：WWBD六原则核心术语

### 原则一：圆圈法则 | Circle of Competence

| 维度 | 内容 |
|------|------|
| **英文** | Circle of Competence |
| **中文** | 能力圈/圆圈法则 |
| **定义** | 只投资、只创业、只做自己真正理解的领域。超出能力圈的事，无论多诱人都不碰。 |
| **Buffett原文** | "You don't have to be an expert on every company, or even many. You only have to be able to evaluate companies within your circle of competence. The size of that circle is not very important; knowing its boundaries, however, is vital." |
| **中文翻译** | "你不必是每家公司、甚至很多公司的专家。你只需要能够评估你能力圈内的公司。那个圈的大小并不重要；然而，知道它的边界至关重要。" |
| **古今对照** | Franklin 印刷所（在学徒期建立能力圈）→ 现代：Upwork（技能变现前先在能力圈内积累） |
| **应用公式** | 能力圈 = 你做过的事 + 你读过的书 + 你交过的人 + 你亏过的钱 |

### 原则二：护城河思维 | Moat Thinking

| 维度 | 内容 |
|------|------|
| **英文** | Economic Moat |
| **中文** | 护城河/经济护城河 |
| **定义** | 企业抵御竞争对手、维持长期超额利润的能力。包括品牌、成本优势、网络效应、转换成本、规模效应、法定垄断等。 |
| **Buffett原文** | "The key to investing is not assessing how much an industry is going to affect society, or how much it will grow, but rather determining the competitive advantage of any given company and, above all, the durability of that advantage." |
| **中文翻译** | "投资的关键不是评估一个行业将对社会产生多大影响，或它将增长多少，而是确定任何给定公司的竞争优势，最重要的是，该优势的持久性。" |
| **古今对照** | Montgomery Ward 邮购（目录=信任护城河）→ 现代：Substack Newsletter（邮件列表=注意力护城河） |
| **微型护城河清单** | ①位置（好点位）②时间（先占位）③信任（个人品牌）④习惯（订阅锁定）⑤成本（规模效应） |

### 原则三：复利耐心 | Compound Patience

| 维度 | 内容 |
|------|------|
| **英文** | Compound Interest / The Power of Compounding |
| **中文** | 复利/复利耐心 |
| **定义** | 不追求单次暴利，而是通过持续的小额积累，让增长呈指数曲线。时间越长，效果越惊人。 |
| **Buffett原文** | "Life is like a snowball. The important thing is finding wet snow and a really long hill." |
| **中文翻译** | "人生就像滚雪球。重要的是找到湿雪和一条足够长的山坡。" |
| **古今对照** | Buffett 弹球机（8台并行，利润全部再投资）→ 现代：SaaS MRR（每月收入自动累积） |
| **72法则** | 用72除以年化收益率，得出资金翻倍所需年数。例如年化18%，4年翻倍。 |

### 原则四：逆向思考 | Inversion

| 维度 | 内容 |
|------|------|
| **英文** | Inversion |
| **中文** | 逆向思考/倒置 |
| **定义** | 不要先想"如何成功"，而是先想"如何失败"，然后避免这些失败路径。 |
| **Buffett原文** | "Charlie and I have not learned how to solve difficult business problems. What we have learned is to avoid them." |
| **中文翻译** | "查理和我没有学会如何解决困难的商业问题。我们学会的是避开它们。" |
| **芒格补充** | "Invert, always invert. Many hard problems are best solved when they are addressed backward." |
| **古今对照** | Fitze 肥皂（先卖别人的货验证市场，避免建厂亏损）→ 现代：SaaS先推MVP验证需求 |
| **失败清单模板** | ①资金耗尽 ②没有客户 ③被竞争者复制 ④自己失去兴趣 ⑤政策变化 |

### 原则五：能力定价 | Ability Pricing

| 维度 | 内容 |
|------|------|
| **英文** | Pricing Power / Value-Based Pricing |
| **中文** | 能力定价/按价值定价 |
| **定义** | 价格不由成本决定，而由你为客户创造的价值决定。你的收入上限 = 你解决的问题的价值。 |
| **Buffett原文** | "The single most important decision in evaluating a business is pricing power. If you've got the power to raise prices without losing business to a competitor, you've got a very good business." |
| **中文翻译** | "评估一家企业时，最重要的单一决策是定价权。如果你有能力提价而不失去业务给竞争者，你就拥有一家非常好的企业。" |
| **古今对照** | Gurney 每日一花（卖"被想起"的感觉，非花本身）→ 现代：知识付费（卖"节省的时间"，非课程本身） |
| **定价公式** | 价格 = 客户省下的时间 × 客户的时间价值 + 情感溢价 |

### 原则六：安全边际 | Margin of Safety

| 维度 | 内容 |
|------|------|
| **英文** | Margin of Safety |
| **中文** | 安全边际 |
| **定义** | 永远给自己留有余地。买入价远低于内在价值，创业时保留足够现金储备，不把全部筹码押上。 |
| **Buffett原文** | "On the margin of safety, which means, don't try and drive a 9,800-pound truck over a bridge that says it's limited to 10,000 pounds. But go down the road a little bit and find one that says 15,000 pounds." |
| **中文翻译** | "关于安全边际，意思是，不要试图驾驶一辆9,800磅的卡车通过一座限重10,000磅的桥。而是沿着路再开远一点，找一座限重15,000磅的桥。" |
| **古今对照** | 玩偶医院（在家操作，零租金；材料来自旧物，零成本）→ 现代：Upwork起步（零启动资金，时间即成本） |
| **安全边际检查清单** | ①如果3个月没收入，我能活吗？ ②最大可承受损失是多少？ ③最差情况能否退出并保留80%本金？ |

## 第二部分：六大商业原型核心术语

### 原型一：留置销售 | Placement / Consignment

| 维度 | 内容 |
|------|------|
| **英文** | Placement Business / Consignment Model |
| **中文** | 留置销售/寄售/点位经济 |
| **定义** | 把设备、商品或服务"放"到别人的场地/平台/流量池中，被动产生收入，与场地方分成。 |
| **核心公式** | 收入 = 点位数量 × 单点日收 × 分成比例 |
| **关键变量** | ①选址能力（人流×停留时间×消费意愿）②设备可靠性③场地方关系维护 |
| **古今术语对照** | penny-weight scales（体重秤）→ 共享充电宝；pinball machine（弹球机）→ 共享按摩椅；soap consignment（肥皂寄售）→ 无人售货机 |
| **风险点** | 点位被竞争者替换、设备故障率高、场地方分成谈判恶化 |
| **Buffett视角** | "这是用最少的主动管理换取被动收入的极致形式。但护城河很薄——别人也能放一台机器在旁边。" |

### 原型二：制造售卖 | Making & Selling

| 维度 | 内容 |
|------|------|
| **英文** | Manufacturing & Direct Sales |
| **中文** | 制造售卖/手作直销 |
| **定义** | 低成本手工或小批量生产商品，直接销售给消费者，赚取生产端与零售端的差价。 |
| **核心公式** | 利润 = （售价 - 原料成本 - 时间成本）× 销量 |
| **关键变量** | ①差异化（新鲜/手工/定制）②场景绑定（影院/学校/活动）③复购率 |
| **古今术语对照** | candied popcorn（焦糖爆米花）→ 手工零食微商；potato chips（薯片）→ 义乌小商品；handicrafts（手工艺品）→ Etsy/DIY |
| **风险点** | 规模化瓶颈、食品安全/质量监管、时间成本高 |
| **Buffett视角** | "这是最古老的商业模式。问题是：你能不能在厨房做出的东西，在工厂做不到？如果答案是'新鲜'或'定制化'，你就有护城河。" |

### 原型三：邮购直销 | Mail-Order / Direct Response

| 维度 | 内容 |
|------|------|
| **英文** | Mail-Order Business / Direct-to-Consumer (DTC) |
| **中文** | 邮购直销/直面消费者 |
| **定义** | 绕过所有中间商（批发商、零售商），通过目录/邮件/互联网直接触达消费者，用信息透明和低价建立信任。 |
| **核心公式** | 利润 = （零售价 - 批发价 - 获客成本）× 客户数 × 复购次数 |
| **关键变量** | ①获客成本（CAC）②客户终身价值（LTV）③退货率④复购率 |
| **古今术语对照** | mail-order catalog（邮购目录）→ SaaS Landing Page；order by mail（邮购下单）→ 电商结账；money-back guarantee（全额退款）→ Freemium免费试用 |
| **风险点** | 获客成本上升、信任建立周期长、物流/交付成本 |
| **Buffett视角** | "Montgomery Ward的伟大之处在于：他把'信任'变成了一种可以规模化生产的商品。目录就是信任的批量传递。" |

### 原型四：服务变现 | Service Monetization

| 维度 | 内容 |
|------|------|
| **英文** | Service Business / Freelancing |
| **中文** | 服务变现/技能变现 |
| **定义** | 用个人技能、时间或专业知识直接为客户解决问题，按小时/项目/结果收费。 |
| **核心公式** | 收入 = 时薪 × 工时 = 项目单价 × 项目数 = 结果价值 × 分成比例 |
| **关键变量** | ①技能稀缺性②客户获取效率③交付质量④从时间到产品的转化能力 |
| **古今术语对照** | rug washing（洗地毯服务）→ 家政O2O；flower delivery（送花服务）→ 跑腿/众包；delivery service（配送服务）→ 外卖骑手 |
| **风险点** | 时间天花板（一天只有24小时）、客户依赖、技能贬值 |
| **Buffett视角** | "Franklin的聪明之处在于：他没有一直'卖时间'，而是把印刷所变成了'卖产品'（报纸、年鉴）。服务是起点，但产品化才是终点。" |

### 原型五：翻新转售 | Refurbishment & Resale

| 维度 | 内容 |
|------|------|
| **英文** | Refurbishment / Resale / Circular Economy |
| **中文** | 翻新转售/循环经济/二手经济 |
| **定义** | 低价收购旧物/废弃物，通过修复、清洁、美化后加价卖出，赚取"修复价值"与"废品价值"之间的差价。 |
| **核心公式** | 利润 = （修复后售价 - 收购价 - 修复成本 - 时间成本） |
| **关键变量** | ①货源稳定性（旧物来源）②修复技能③销售渠道④定价能力（情感价值挖掘） |
| **古今术语对照** | doll hospital（玩偶医院）→ 手机维修；second-hand equipment（二手设备翻新）→ 翻新电子产品；repair café（修理咖啡馆）→ 社区维修站 |
| **风险点** | 货源不稳定、修复失败率高、消费者 stigma（"旧的就是差的"偏见） |
| **Buffett视角** | "这是我最欣赏的商业模式之一。你在别人看到'垃圾'的地方看到'价值'。关键是：你的修复成本必须远低于新品成本的某个百分比。" |

### 原型六：内容/策展 | Content & Curation

| 维度 | 内容 |
|------|------|
| **英文** | Content Business / Curation / Information Arbitrage |
| **中文** | 内容变现/策展经济/信息套利 |
| **定义** | 通过筛选、整理、解释、传播信息，为受众节省时间和认知成本，从而获得注意力、信任度和变现能力。 |
| **核心公式** | 价值 = 受众节省的时间 × 信息质量 × 受众数量 |
| **关键变量** | ①内容生产能力②分发渠道③受众信任度④从注意力到交易的转化效率 |
| **古今术语对照** | seed catalog（种子目录）→ 产品评测 newsletter；radio show（广播节目）→ 播客/Podcast；almanack（年鉴）→ 年度行业报告；sales copy（销售文案）→ Landing Page文案 |
| **风险点** | 内容同质化、平台算法依赖、注意力碎片化 |
| **Buffett视角** | "Henry Field每晚在广播里讲故事，最后推销种子。这是'教育式营销'的原始形态。你今天在Substack做的事，和他1930年在广播里做的事，本质没有区别——用内容建立信任，用信任完成交易。" |

## 第四部分：量化指标术语

### 微型商业核心指标

| 术语 | 英文 | 定义 | 健康基准 |
|------|------|------|----------|
| 启动资金 | Startup Capital | 从零到第一次收入所需的全部投入 | <$1,000（微观商业） |
| 回本周期 | Payback Period | 初始投资收回所需时间 | <6个月（优秀） |
| 单点日收 | Daily Revenue per Unit | 单个点位/设备的日收入 | ¥10-100（因品类而异） |
| 场地方分成 | Location Split | 收入中与场地方分享的比例 | 20-50% |
| 利润率 | Net Margin | 扣除所有成本后的净利润占比 | >20%（健康） |
| 复购率 | Repeat Rate | 客户第二次购买的比例 | >30%（优秀） |
| 获客成本 | CAC | 获取一个新客户的成本 | <客户首单价值的30% |
| 客户终身价值 | LTV | 一个客户在整个生命周期内的总价值 | >3×CAC |

### SaaS/订阅制指标

| 术语 | 英文 | 定义 | 健康基准 |
|------|------|------|----------|
| MRR | Monthly Recurring Revenue | 月经常性收入 | 持续增长 |
| ARR | Annual Recurring Revenue | 年经常性收入 | MRR×12 |
| Churn Rate | Churn Rate | 客户流失率 | <5%/月 |
| 免费→付费转化率 | Freemium Conversion | 免费用户转为付费用户的比例 | 2-5% |
| 免费试用转化率 | Trial Conversion | 试用用户转为付费的比例 | 15-25% |
| NRR | Net Revenue Retention | 净收入留存（老客户的收入变化） | >100% |
| ARPU | Average Revenue Per User | 每用户平均收入 | 持续上升 |
