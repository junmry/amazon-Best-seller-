## 三、标题埋词策略

### 3.1 标题公式（180-190 字符）
```
[Brand] + [数量] + [款式/功能词] + [材质] + Bar Stools + [尺码高度] + [场景词] + [附加功能/人群], [颜色]
```

**字符控制：** 180-190 字符（含空格）。
**去重规则：** 同一词在单标题中最多出现 2 次。
**唯一性规则：** 每个变体标题必须不同，禁止复制粘贴只改颜色。

### 3.2 变体标题示例

## 七、竞品差距与差异化动作

### 7.1 BSR 数据中发现的显性差距
| 维度 | 当前市场标配 | 我方机会/动作 |
|---|---|---|
| A+ 页面 | 98% 都有 | **必须做**，缺少 A+ 直接掉出前 50 竞争圈 |
| 主图视频 | 80% 都有 | **必须补**，主图视频转化率提升 15-30% |
| 变体数量 | 平均 17.5 个 | 建议覆盖 3-5 颜色 × 2-3 高度 × 2 数量组合（Set of 2 / 4） |
| 评分 | 平均 4.47 | 新品期必须做到 4.3+，Vine 计划 + 售后跟进缺一不可 |
| 评论数 | 平均 1,681 | 前 6 个月目标 50+，第 1 年目标 200+ |
| AC 标 | 85 个 | 精准卡位大词 + 保持转化率和库存深度，AC 是可抢夺的 |

### 7.2 标题差异化机会
BSR Top 100 中大量标题堆砌功能词但缺乏人群和场景细分。建议我们切入：
- **细分人群**：heavy duty / big and tall / short person / petite
- **细分场景**：patio / outdoor / man cave / basement / rv / studio apartment
- **细分风格**：western saddle / bohemian / coastal / art deco（竞争度低）

### 7.3 价格战建议
- **流量款**：$79-99（Set of 2 / 基础款 / 无 swivel）—— 冲销量、抢 AC
- **利润款**：$129-169（Set of 2 或 Set of 4 / swivel / adjustable / 高材质）—— 主力盈利
- **形象款**：$199-249（Set of 4 / 高端材质 / 设计师款）—— 拉升品牌调性
