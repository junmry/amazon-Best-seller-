## 二、标题埋词公式

### 2.1 标准公式

```
[Brand] + [Size/Height] + [Style] + [Material] + [Core Product] + [Key Feature], [Scene], [Color], [Set Qty]
```

### 2.2 字符与规则
- **严格控制在 180-190 字符**（含空格）
- ** MUST 包含：** 尺寸（24"/26"/30" counter height / bar height）+ 核心词（bar stools）+ 场景（kitchen island）+ 数量（set of 2/4）
- **禁止重复堆砌：** 同一个词在单标题中最多出现 2 次
- **变体差异化：** 不同颜色/尺寸变体，标题必须完全不同

## 三、五点描述（Bullet Points）埋词模板

### 通用埋词结构

**Bullet 1 — 尺寸适配 + 核心场景**
> These **[Height] bar stools** are perfectly sized for **[kitchen island/counter/bar]** heights of **[36-39 inches / 40-42 inches]**. Whether used in your kitchen, home bar, or dining area, they offer comfortable seating for everyday meals and social gatherings.

**埋词：** counter height / bar height / kitchen island / home bar / dining area / comfortable seating

**Bullet 2 — 材质 + 工艺 + 承重力**
> Crafted from **[solid wood/metal frame/faux leather]**, these stools feature a **[saddle seat/upholstered seat/with back]** designed for long-lasting comfort. The sturdy construction supports up to **[300/330/400 lbs]**, ensuring durability for both residential and commercial use.

**埋词：** solid wood / metal frame / faux leather / upholstered / saddle seat / sturdy construction / 300 lbs / durable

**Bullet 3 — 功能卖点（旋转/调节/ footrest）**
> Designed for convenience, the **[360° swivel/adjustable height/footrest]** allows you to customize your seating experience. The **[ergonomic backrest/lumbar support]** reduces pressure during extended sitting, making these stools ideal for busy kitchens and entertainment spaces.

**埋词：** 360° swivel / adjustable height / footrest / ergonomic / backrest / lumbar support / entertainment spaces

**Bullet 4 — 风格 + 使用场景延展**
> With a **[modern/farmhouse/rustic/industrial]** aesthetic, these bar stools blend seamlessly into various interiors. Perfect for **[kitchen islands, breakfast bars, patios, cafes, pubs, and lounges]** — adding both style and function to any space.

**埋词：** modern / farmhouse / rustic / industrial / kitchen islands / breakfast bars / patios / cafes / pubs / lounges

**Bullet 5 — 安装 + 包装 + 售后保障（避免违禁词）**
> Each set arrives with all necessary hardware and step-by-step instructions for quick assembly. The **[Set of 2/Set of 4]** is securely packaged to ensure safe delivery. Please note that boxes may arrive on different days if shipped separately.

**埋词：** set of 2 / set of 4 / quick assembly / hardware included / securely packaged
