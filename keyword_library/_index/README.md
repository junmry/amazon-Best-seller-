# 词库使用指南

## 目录结构

```
keyword_library/                 # 词库总目录
├── _index/                     # 索引与导航（你在的位置）
├── _广告词库/                   # 跨类目通用广告词库
│
├── 沙发_Sofa/                  # 一级类目：沙发
├── 椅子_Chair/                 # 一级类目：椅子
├── 吧凳_Barstool/              # 一级类目：吧凳
├── 户外家具_Outdoor/            # 一级类目：户外家具
├── 餐桌套装_DiningSets/         # 一级类目：餐桌套装
├── 玄关桌_ConsoleTable/         # 一级类目：玄关桌/沙发桌
├── 桌布_Tablecloth/            # 一级类目：桌布
├── 人体工学椅_Ergonomic/         # 一级类目：人体工学办公椅
└── 游戏椅_GamingChair/          # 一级类目：游戏椅
```

## 类目内子目录规范

每个类目下统一使用以下子目录：

| 目录 | 用途 | 文件类型 |
|------|------|----------|
| `01_原始数据/` | 原始词表、爬虫数据、未处理的关键词 | .csv, .xlsx, .json |
| `02_拆词结果/` | 多层级拆词结果（主词/副词/次副词） | .xlsx |
| `03_结构化词库/` | 结构化埋词库、JSON词库 | .json, .xlsx |
| `04_埋词素材/` | 埋词指南、关键词素材库、写作指引 | .md, .txt |
| `05_标题输出/` | 生成的标题、Listing优化结果 | .xlsx, .csv |
| `06_广告词库/` | 广告专用词库、流量词、捡漏词 | .xlsx, .json |

## 新增类目流程

当你有新类目的词库需要处理时：

1. **创建类目目录**
   ```bash
   mkdir -p keyword_library/新类目_英文名/{01_原始数据,02_拆词结果,03_结构化词库,04_埋词素材,05_标题输出,06_广告词库}
   ```

2. **放入原始数据**
   - 将原始关键词文件放入 `01_原始数据/`
   - 支持格式：.csv, .xlsx, .json

3. **执行拆词处理**
   - 使用 `scripts/tools/split_words.py` 进行拆词
   - 输出到 `02_拆词结果/`

4. **更新本索引**
   - 在 [类目清单](./类目清单.md) 中添加新类目条目

## 文件命名规范

| 类型 | 命名格式 | 示例 |
|------|----------|------|
| 原始词表 | `{类目}_原始词表_{日期}.xlsx` | `沙发_原始词表_2026-03-01.xlsx` |
| 拆词结果 | `{类目}_关键词拆词_完整层级.xlsx` | `沙发_关键词拆词_完整层级V2.xlsx` |
| 结构化词库 | `{类目}_埋词库_结构化.json` | `沙发_埋词库_结构化.json` |
| 埋词素材 | `{类目}_埋词素材库.md` | `沙发_埋词素材库.md` |
| 标题输出 | `KEIKI_{产品}_{版本}.xlsx` | `KEIKI_Boneless_新标题.xlsx` |

## 快速查找

- **找拆词结果** → `keyword_library/{类目}/02_拆词结果/`
- **找埋词素材** → `keyword_library/{类目}/04_埋词素材/`
- **找广告词库** → `keyword_library/_广告词库/`
- **找脚本工具** → `scripts/tools/`
