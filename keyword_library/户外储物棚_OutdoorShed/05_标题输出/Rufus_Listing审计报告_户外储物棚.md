## Executive Summary

该Listing关键词数据丰富，已覆盖核心品类大词（shed / outdoor shed / storage shed）。
但当前数据更像「关键词列表」，缺少围绕用户问题形成的答案结构。
最大机会在于强化 **场景化名词短语**（如 backyard tool shed, waterproof garden storage, small patio shed），
让页面更容易进入「问题 -> 答案 -> 名词短语 -> 商品推荐」的Rufus链路。

## Priority Fixes

1. **重写标题为场景化名词短语** — 当前关键词堆砌风险高，需改为「尺寸+材质+场景+品类」结构
2. **强化替代方案防御** — 针对 deck box / storage cabinet / garage 植入对比语义
3. **补充Q&A结构描述** — 用自然语言问答覆盖 backyard / garden / patio 场景
4. **增加配件关联** — shelf / anchor kit / foundation 等配件词埋入描述
5. **高流量否定词过滤** — outdoor furniture / shelves / storage bins 等高流量但低相关词需否定
