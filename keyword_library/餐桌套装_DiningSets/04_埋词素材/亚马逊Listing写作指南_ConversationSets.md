# 亚马逊Listing写作指南 - Conversation Sets类目

## 一、标题写作规范

### 1.1 基础规则
| 项目 | 规范 |
|------|------|
| 长度 | 150-200字符（最佳169字符） |
| 开头 | 品牌名 或 件套数 |
| 结构 | 品牌 → 件套 → 场景 → 材质 → 产品词 → 款式 → 功能 → 颜色 |
| 禁止 | 重复词超过2次、敏感词、竞品品牌名 |

### 1.2 埋词优先级（必埋→选埋）

**Tier 1 - 必埋（100%出现）**
- `patio` - 类目核心词
- `furniture` / `set` - 产品类型
- `outdoor` - 场景大词

**Tier 2 - 高优先（70%+出现）**
- `wicker` / `rattan` - 主流材质
- `conversation` - 类目精确词
- `table` / `chairs` / `sofa` - 产品组件
- `cushions` - 卖点词

**Tier 3 - 差异化（选埋）**
- 件套数：`3 piece`, `4 piece`, `5 piece`, `7 piece`
- 场景细分：`garden`, `backyard`, `porch`, `balcony`, `deck`
- 款式：`sectional`, `modular`, `modern`
- 功能：`weather-resistant`, `easy assembly`

### 1.3 标题公式模板

```
[品牌] + [件套数] + [场景词] + [材质] + [产品词] + [款式] + [功能/卖点] + [颜色]
```

**示例：**
```
KEIKI 7-Piece Patio Furniture Set PE Rattan Wicker Outdoor Conversation Set with Coffee Table, Modern Sectional Sofa with Cushions for Backyard Garden Porch, Brown
```

### 1.4 不同定位的标题策略

| 定位 | 标题侧重 | 示例关键词 |
|------|----------|------------|
| 性价比 | affordable, budget-friendly | cheap, value, under $100 |
| 品质感 | premium, durable, sturdy | high-quality, heavy-duty |
| 现代风 | modern, contemporary, stylish | sleek, minimalist |
| 经典风 | classic, traditional, elegant | timeless, vintage |

## 二、五点描述（Bullet Points）写作规范

### 2.1 结构框架

**五点必备卖点类型（覆盖率参考）：**

| 顺序 | 卖点类型 | 覆盖率 | 内容重点 |
|------|----------|--------|----------|
| 1 | 材质工艺 | 100% | PE rattan, steel frame, weather/UV resistant |
| 2 | 舒适体验 | 99% | thick cushions, soft seating, ergonomic |
| 3 | 空间场景 | 100% | patio, outdoor, garden, backyard |
| 4 | 安装使用 | 91% | easy assembly, quick setup, tools included |
| 5 | 包装服务 | 78% | warranty, customer service, after-sales |

### 2.2 每点写作公式

```
[卖点标题]: [核心卖点说明] + [具体细节] + [用户利益] + [可选：场景暗示]
```

**模板示例：**

**Point 1 - 材质工艺**
```
Durable & Weather-Resistant: Crafted from high-quality PE rattan wicker and reinforced steel frame, this patio furniture set is built to withstand outdoor elements including rain, UV rays, and temperature changes for year-round use.
```

**Point 2 - 舒适体验**
```
Superior Comfort: Thick, high-density sponge cushions provide exceptional seating comfort. Removable zippered covers make cleaning effortless, keeping your outdoor space fresh and inviting.
```

**Point 3 - 空间场景**
```
Perfect for Any Outdoor Space: Ideal for patio, backyard, garden, porch, or balcony. This versatile conversation set creates a cozy gathering spot for family and friends to relax and entertain.
```

**Point 4 - 安装使用**
```
Easy Assembly: All hardware and tools included for quick setup. Clear instructions guide you through simple assembly—enjoy your new outdoor furniture within an hour.
```

**Point 5 - 包装服务**
```
Complete Set & Support: Includes 2 single chairs, 1 loveseat, and 1 coffee table. Backed by our responsive customer service team and satisfaction guarantee for worry-free shopping.
```

### 2.3 高频埋词清单（五点必用）

**动词/形容词：**
`durable`, `sturdy`, `comfortable`, `spacious`, `easy`, `quick`, `thick`, `soft`, `modern`, `elegant`, `versatile`

**名词：**
`cushions`, `frame`, `wicker`, `rattan`, `assembly`, `setup`, `tools`, `hardware`, `warranty`, `service`

**场景词：**
`outdoor`, `patio`, `garden`, `backyard`, `porch`, `balcony`, `deck`, `yard`

**功能词：**
`weather-resistant`, `uv-resistant`, `waterproof`, `rust-resistant`, `low maintenance`

## 三、GKW（后台搜索词）埋词策略

### 3.1 GKW写作规则

- 每行最多250字符
- 总共5行
- **不要**使用已在标题和五点中的词
- **不要**使用竞品品牌名
- **不要**重复同义词
- 使用逗号或空格分隔

### 3.2 GKW分层埋词

**第一行 - 核心长尾词**
```
patio furniture set outdoor, wicker conversation set, rattan patio set, outdoor seating set, garden furniture set
```

**第二行 - 场景细分词**
```
backyard patio set, porch furniture set, balcony conversation set, deck seating set, lawn furniture outdoor
```

**第三行 - 材质属性词**
```
pe rattan furniture, resin wicker set, all weather patio furniture, uv resistant outdoor set, waterproof garden furniture
```

**第四行 - 功能用途词**
```
outdoor chat set, patio lounge furniture, garden conversation seating, backyard relax set, outdoor entertaining furniture
```

**第五行 - 人群/规格词**
```
4 piece patio set, 5 piece outdoor furniture, 7 piece wicker set, small patio furniture, compact outdoor seating
```
