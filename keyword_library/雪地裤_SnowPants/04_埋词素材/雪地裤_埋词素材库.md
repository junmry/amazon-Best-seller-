## 四、各维度埋词策略

### 4.1 性别人群 (Gender)

**主词分布：**
- men / men's / mens — 绝对主力，覆盖约202万搜索量
- women — 女性市场，约14万搜索量
- kids / boys / girls / youth — 儿童市场
- plus size / big and tall — 大码需求

**埋词建议：**
- 标题必须包含 men/men's/mens（3种变体都要覆盖）
- 五点描述中分别针对不同人群写差异化卖点
- A+页面可增加"SIZING FOR EVERY BODY"板块，覆盖plus size需求

### 4.2 场景用途 (Activity)

**Top场景：**
1. **winter** (230万搜索量) — 最大场景，泛冬季需求
2. **ski** (60万) — 专业滑雪，客单价高
3. **snowboard** (50万) — 单板群体，年轻化
4. **work** (35万) — 工装需求， durability是关键
5. **hiking** (18万) — 徒步场景，轻量化需求
6. **fishing / hunting / outdoor** — 小众但忠诚度高
7. **ice skating** — 冰上运动，新补充场景

**埋词建议：**
- 标题优先覆盖 winter + ski/snowboard
- 搜索词广告可单独开 campaign：ski pants, snowboard pants, work pants
- 场景图按季节/活动分类展示（滑雪场景图 vs 工装场景图）

### 4.3 功能特性 (Function)

**Top功能：**
1. **fleece lined** (33万) — 最高搜索量功能词，强调"内衬保暖"
2. **waterproof** (33万) — 防水是核心卖点
3. **insulated** (31万) — 保温层技术
4. **thermal** (新增，约4万) — 热能保持
5. **windproof** (5千) — 防风，可跟waterproof组合
6. **reinforced** (1.8万) — 工装耐磨需求

**埋词建议：**
- 标题组合公式：`[人群] + [场景] + [核心功能] + pants`
- 例：mens waterproof insulated ski pants, men's fleece lined work pants
- 五点描述按功能分层：Layer 1防水 → Layer 2保温 → Layer 3耐磨

### 4.4 款式类型 (Style)

**现有款式：**
- cargo (30万) — 工装口袋款，搜索量最高
- bib (少量) — 背带裤款式

**埋词建议：**
- cargo pants 是一个强独立搜索词（19万月搜），可作为独立变体
- bib pants 适合滑雪场景，但搜索量小，不建议作为主打变体

### 4.5 材质面料 (Material)

**主要材质：**
- softshell — 软壳，适合户外活动
- nylon / polyester — 合成纤维，耐用
- cotton / canvas / duck — 工装经典材质
- fleece — 保暖内衬

**埋词建议：**
- 材质描述不要只说"high quality fabric"，要具体到"water-resistant softshell outer + fleece-lined inner"
- 利用"tactile layering"趋势（家具趋势迁移），强调面料层次感和触感对比

### 4.6 品牌竞争词

**被搜索的品牌：**
- Carhartt (11万) — 工装标杆
- Dickies (6.7万) — 工装+性价比
- Amazon Essentials (12万) — 低价走量
- Arctix (5.6万) — 滑雪平价品牌
- Columbia / North Face — 户外大牌

**埋词建议：**
- 广告否定词库必须包含竞争对手品牌名（除非你做品牌对比广告）
- Listing中避免直接提及竞争品牌，但可以在对比图/QA中暗示"compare to leading brands"

### 4.7 颜色偏好

**搜索颜色：**
- black (10万) — 绝对主导
- navy / blue
- olive / green
- grey / gray
- brown / tan / khaki
- camo — 工装/狩猎场景

**埋词建议：**
- 主图建议用黑色或navy，CTR数据通常更好
- 变体命名直接放颜色词：Black, Navy, Olive, Grey, Khaki, Camo

### 4.8 西班牙语市场

**西语关键词：**
- pantalones de nieve (snow pants)
- pantalones para hombre (men's pants)
- pantalones impermeables (waterproof pants)
- pantalones termicos (thermal pants)

**埋词建议：**
- 后端搜索词（Backend Keywords）可埋入西班牙语词
- 考虑创建西班牙语A+内容变体或单独ASIN（针对拉美市场）
