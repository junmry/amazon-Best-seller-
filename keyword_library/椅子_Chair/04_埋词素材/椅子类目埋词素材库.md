## 三、标题埋词公式

### 基础公式

```
[Brand] + [颜色/材质] + [款式/功能] + [核心产品词] + [场景] + [人群/尺码] + [差异化卖点]
```

### 字符控制
- **严格 180-190 字符**（含空格）
- ≥180 且 ≤190
- 每个变体标题必须**独一无二**
- 禁止标题间复制粘贴改个颜色

## 四、五点描述（Bullet Points）埋词策略

### 核心原则
- 禁止具体尺寸数字（如 72"/78"）
- 禁止颜色词汇
- 保持内容通用，适用于**所有变体**
- 每点聚焦一个维度：场景 + 人群 + 功能 + 材质 + 安装

### 五点模板

| 点位 | 埋词方向 | 推荐词根 | 示例 |
|------|---------|---------|------|
| **Point 1** | 场景 + 人群 | living room, bedroom, apartment, office, nursery, adults, family | 专为现代客厅、卧室或家庭办公室设计，适合追求舒适与风格的成年人使用 |
| **Point 2** | 材质 + 触感 | velvet, linen, faux leather, chenille, boucle, breathable | 采用高品质面料，触感柔软透气，久坐不闷热，提升整体家居质感 |
| **Point 3** | 功能 + 人体工学 | ergonomic, lumbar support, adjustable, reclining, swivel, glider | 人体工学设计，配备可调节支撑结构，帮助缓解久坐疲劳，保护脊椎健康 |
| **Point 4** | 安装 + 维护 | easy assembly, tool-free, 15 minutes, easy clean, durable | 简易组装设计，无需专业工具，15分钟即可完成安装，日常清洁维护轻松省心 |
| **Point 5** | 品质承诺 + 适用性 | heavy duty, sturdy frame, weight capacity, versatile, multi-purpose | 坚固框架结构，承重力强，经久耐用，适用于多种生活场景，满足全家使用需求 |

### 五点描述完整示例（Accent Chair）

```
• 【多场景适用】专为客厅、卧室、阅读角或公寓小空间设计，是提升家居格调的理想选择，适合追求品质生活的现代家庭
• 【优质面料】采用高密度软包面料，触感细腻柔软，透气性佳，久坐舒适不闷热，为居家时光增添温馨质感
• 【人体工学支撑】弧形靠背贴合人体曲线，配备加厚坐垫，有效分散压力，提供长时间坐姿所需的舒适支撑
• 【简易安装】无需复杂工具，按照说明书步骤可在15分钟内完成组装，省时省力，即刻享受舒适座椅
• 【稳固耐用】内置坚固木框架，搭配金属支撑腿，结构稳定承重力强，确保日常使用中的安全与持久耐用
```

## 七、A+ 描述埋词策略

### 模块1：品牌故事 / 场景引入
- 埋入：品牌名 + 核心场景词（living room, bedroom, office）
- 目的：建立品牌心智 + 场景联想

### 模块2：产品卖点展开（2-3个模块）
- 模块A：材质 + 触感 → velvet, linen, faux leather, breathable, soft touch
- 模块B：功能 + 人体工学 → ergonomic, lumbar support, adjustable, reclining
- 模块C：安装 + 维护 → easy assembly, 15 minutes, tool-free, easy clean

### 模块3：场景展示图配文
- 每张图配一个场景词 + 人群词
- 示例图配文：
  - "Perfect for your living room relaxation" → living room, relaxation, lounge
  - "Ideal nursery companion for new moms" → nursery, new moms, breastfeeding, glider
  - "Stylish addition to your home office" → home office, desk, task, ergonomic
  - "Cozy reading nook essential" → reading, nook, bedroom, corner

### 模块4：规格参数 / 对比表
- 此处可以放具体尺寸（A+允许）
- 埋入：weight capacity, dimensions, materials, care instructions

## 八、高风险词黑名单

**以下词汇严禁出现在 Listing 任何位置（标题、五点、A+、后台）：**

| 风险类别 | 禁用词 | 原因 |
|---------|-------|------|
| 售后客服 | warranty, guarantee, refund, return policy, money back, satisfaction guaranteed | 亚马逊政策违规 |
| 母婴敏感 | baby safe, child proof, non-toxic, organic, hypoallergenic（无认证） | 需认证，无认证=违规 |
| 医疗宣称 | therapeutic, medical grade, doctor recommended, FDA approved（无认证） | 医疗器械法规 |
| 杀虫剂/化学 | pest control, bug repellent, antibacterial, antimicrobial（无认证） | 高风险类目 |
| 电池相关 | battery included, rechargeable, lithium（非电池产品） | 无关且触发审核 |
| 竞品品牌 | 任何竞品品牌名（如 IKEA, Ashley, Lazy Boy, Herman Miller） | 侵权风险 |
| 平台词汇 | amazon, best seller, top seller, amazon's choice, prime | 平台政策违规 |
| 绝对化用语 | best, #1, top rated, highest quality, perfect, ultimate, unbeatable | 广告法/平台违规 |

| 颜色误导 | blue（实际是 beige 变体） | 变体信息错误 |
