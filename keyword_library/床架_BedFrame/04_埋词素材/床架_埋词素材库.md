## 十一、埋词组合公式

### 标题结构模板
```
[尺寸] + [款式] + [功能] + [材质] + [风格] + [根词] + [场景]
```

**示例：**
- `Queen Platform Bed Frame with Storage Drawers, Solid Wood, Modern Farmhouse Style, No Box Spring Needed`
- `King Size Upholstered Bed Frame with Headboard and Footboard, Velvet, Luxury Bedroom Furniture`
- `Twin Metal Bed Frame with Trundle, Easy Assembly, Kids Room, Heavy Duty Steel`

### 五点描述埋词策略
1. **第一句** — 尺寸 + 款式 + 核心功能（主根词 + 最大流量词）
2. **第二句** — 材质 + 风格（质感描述 + 风格定位）
3. **第三句** — 具体功能细节（storage/drawers/headboard 等）
4. **第四句** — 安装/结构卖点（easy assembly / no box spring / heavy duty）
5. **第五句** — 场景/人群/售后（bedroom / small space / warranty）

### 后台通用关键词（GKW）策略
- **必埋根词**：bed frame, platform bed, storage bed, bed frame with drawers
- **尺寸组合**：king bed frame, queen size bed frame, twin bed frame with storage
- **功能长尾**：bed frame with headboard and footboard, adjustable bed frame with remote
- **风格长尾**：modern farmhouse bed frame, mid century platform bed
- **场景长尾**：bed frame for small spaces, apartment bed frame, dorm bed frame
