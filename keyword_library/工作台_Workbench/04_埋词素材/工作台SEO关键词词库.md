## 三、埋词优先级建议

### 【标题公式】
```
[Brand] + [核心产品] + [核心卖点: wheels/rolling] + [场景] + [特征] + [材质] + [功能]
```

**示例**:
> Rolling Workbench with Wheels for Garage, Heavy Duty Mobile Work Table with Storage, Adjustable Height Steel Workshop Bench, Portable Work Bench on Casters

### 【五点描述模板】

1. **移动性 + 重型结构** — Mobile workbench with 4 locking casters, heavy-duty steel frame supports up to X lbs, easily move around garage or workshop
2. **可调节 + 多功能** — Adjustable height from X to X inches, multi-purpose work surface for woodworking, repairs, crafting, or tool organization
3. **材质 + 耐用性** — Stainless steel top / metal frame with powder-coated finish, rust-resistant, built to withstand years of heavy use
4. **场景 + 目标人群** — Perfect for garage, workshop, shop, or basement — ideal for DIYers, mechanics, woodworkers, and hobbyists
5. **收纳 + 安装** — Built-in storage drawers / pegboard / tool tray, easy assembly with clear instructions, all hardware included

### 【后台搜索词（Search Terms）】

**空格分隔，不带标点，250字符以内：**
```
rolling workbench mobile work table with wheels garage workshop heavy duty adjustable height steel metal portable on casters storage drawers tool bench work station mechanic diy woodworker
```

**备用变体组合：**
```
foldable work bench with wheels portable garage worktable stainless steel top work station adjustable height mobile tool bench heavy duty workshop cart rolling table on casters
```

### 【品牌防御 + 长尾组合】
- 长尾防御: `yourbrand workbench`, `yourbrand rolling workbench`, `yourbrand garage work table`
- 功能组合: `workbench with wheels and drawers`, `mobile garage work station`, `rolling tool bench with storage`
- 场景组合: `garage workbench on wheels`, `workshop rolling table`, `shop work bench portable`
